# dagster_pypam

## Configuration and Deployments


`dagster_pypam` runs the [MBARI PBP/PyPAM package](https://github.com/mbari-org/pbp)  as a Dagster workload.

The application is deployed to Amazon EKS and uses configuration files stored in Amazon S3 to discover and process passive acoustic monitoring (PAM) deployments.

Raw audio data must be stored in the ingest S3 bucket. The ingest bucket is currently configured as:

s3://neracoos-pam-data-ingest

Results generated by PyPAM are written to the output S3 bucket, which is currently configured as:

s3://neracoos-pam-output

Both the ingest and output S3 buckets are mounted into the dagster_pypam container. This allows the underlying MBARI processing package to access WAV files from the ingest bucket through the container's filesystem and write the generated NetCDF files to the mounted output bucket.

### Deployment Discovery

Deployments are defined using JSON configuration files.

`dagster_pypam` automatically discovers new deployments when a JSON  file is written to the location specified by the `CONFIG_DIR` environment variable. `CONFIG_DIR` points to an S3 bucket that is mounted into the `dagster_pypam` container. To add a deployment, write a JSON configuration file to this location. Once the configuration is available, `dagster_pypam` will pick up the deployment and make it available for processing.

The current configuration location is:

s3://neracoos-pam-data-ingest/dataset_config/

Configuration files are organized by project:

<CONFIG_DIR>/<project>/<deployment>.json

For example:

s3://neracoos-pam-data-ingest/dataset_config/WellFleet/WellFleet_1_04222014_05212014.json

s3://neracoos-pam-data-ingest/dataset_config/WellFleet/WellFleet_67_06072023_07192023.json

`dagster_pypam` will automatically discover new configuration files and the deployments will be available in the system




### Deployment Configuration

Each deployment is described by a JSON configuration file.

Example:

```json
{
  "project": "WellFleet",
  "deployment": "WellFleet_1_04222014_05212014",
  "global_attrs_uri": "s3://neracoos-pam-data-ingest/dataset_config/WellFleet/global_attributes_wellfleet.yaml",
  "lat": 41.88346667,
  "lon": -70.06395,
  "output_prefix": "WellFleet_1",
  "start_date": "20140422",
  "end_date": "20140521",
  "raw_data": "s3://neracoos-pam-data-ingest/Wellfleet/Wellfleet (1) April 22 2014 - May 21 2014/Soundtrap May 20 2014 Retrieval/Soundtrap May 20 2014 retrieval/",
  "sensitivity_flat_value": 172.9,
  "subset_x": 10,
  "subset_y": 48000,
  "prefix": [
    "67432472"
  ],
  "variable_attrs_uri": "s3://neracoos-pam-data-ingest/variableAttributes_template.yaml",
  "ylim_x": 10,
  "ylim_y": 72000,
  "cmlim_x": 50,
  "cmlim_y": 105,
  "recorder_type": "SOUNDTRAP"
}
```

### Configuration Fields

| Field                    | Description                                                                           |
| ------------------------ | ------------------------------------------------------------------------------------- |
| `project`                | Project name.                                                                         |
| `deployment`             | Unique name identifying the deployment.                                               |
| `global_attrs_uri`       | S3 URI of the YAML file containing global dataset attributes.                         |
| `lat`                    | Latitude of the deployment.                                                           |
| `lon`                    | Longitude of the deployment.                                                          |
| `output_prefix`          | Prefix used when naming generated output files.                                       |
| `start_date`             | Start date of the deployment in `YYYYMMDD` format.                                    |
| `end_date`               | End date of the deployment in `YYYYMMDD` format.                                      |
| `raw_data`               | S3 URI containing the raw WAV data for the deployment.                                |
| `sensitivity_flat_value` | Flat recorder sensitivity value used during acoustic processing.                      |
| `subset_x`               | X parameter used when generating subset products.                                     |
| `subset_y`               | Y parameter used when generating subset products.                                     |
| `prefix`                 | One or more filename prefixes used to identify WAV files belonging to the deployment. |
| `variable_attrs_uri`     | S3 URI of the YAML file containing variable-level attributes.                         |
| `ylim_x`                 | X-axis parameter used for configured processing or visualization limits.              |
| `ylim_y`                 | Y-axis parameter used for configured processing or visualization limits.              |
| `cmlim_x`                | X parameter used for configured color-map limits.                                     |
| `cmlim_y`                | Y parameter used for configured color-map limits.                                     |
| `recorder_type`          | Recorder type associated with the deployment.                                         |




### Optional Configuration Fields

The following configuration fields are optional:

| Field                              | Description                                                              |
| ---------------------------------- | ------------------------------------------------------------------------ |
| `compress_netcdf`                  | Enables compression of generated NetCDF output.                            |
| `add_quality_flag`                 | Enables generation or inclusion of quality flags in the output.            |
| `exclude_tone_calibration_seconds`  | Specifies tone-calibration data that should be excluded from processing.    |
| `max_segments`                    | Limits the number of segments processed.                                    |
| `voltage_multiplier`               | Applies a voltage multiplier during processing.                            |

If an optional field is omitted, the default value of the MBARI package will be used.

### Supported Recorder Types

The `recorder_type` field identifies the type of acoustic recorder associated with the deployment.

Supported values are:

```text
NRS
RESEA
SOUNDTRAP
ICLISTEN
```

`recorder_type` should match one of these values exactly.

### Output

Processed results are written to the location configured by the `OUTPUT_DIR` environment variable.

The currently configured output bucket is:

```text
s3://neracoos-pam-output
```

Deployment output is organized under the output bucket using the project and deployment identifiers, with generated netCDF/JPEF files stored in an `output/` directory:

```text
<OUTPUT_DIR>/<project>/<deployment>/output/
```

For example:

```text
s3://neracoos-pam-output/WellFleet/WellFleet_1_04222014_05212014/output/
```

Processing produces daily NetCDF files. Each filename consists of the deployment's `output_prefix` followed by the date represented by the file:

```text
<output_prefix><YYYYMMDD>.NC
```

For example, a daily output for April 22, 2014 with:

```json
"output_prefix": "WellFleet_1"
```

would be:

```text
WellFleet_120140422.NC
```
